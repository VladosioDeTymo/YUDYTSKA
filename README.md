# YUDYTSKA

Офіційний сайт української співачки Альони Юдицької (YUDYTSKA) — Чернігів.

Статичний сайт: чистий HTML, CSS та JavaScript, без збірки та без залежностей
у репозиторії. Деплоїться на GitHub Pages як є.

---

## ⚙️ Єдине, що потрібно доналаштувати

Посилання на кліп **«Ідеальні вони»** на YouTube. Відкрийте
[`assets/js/config.js`](assets/js/config.js) і вставте ID відео в перший рядок:

```js
export const YT_ID = 'dQw4w9WgXcQ';   // ID з https://youtu.be/<ID>
```

Поки поле порожнє, блок кліпу показує обкладинку синглу з кнопкою на
YouTube-канал — сайт повністю робочий. Після вставки ID там з'явиться
вбудований плеєр.

Усі інші посилання (Instagram, YouTube, Facebook, Spotify, Telegram, пошта,
публікації ЗМІ, радіо) теж лежать у `config.js` — міняти їх треба тільки там,
у розмітці вони підставляються автоматично через атрибут `data-link`.

## Локальний запуск

Модулі ES не працюють через `file://`, тому потрібен сервер:

```bash
python3 -m http.server 8080
# відкрити http://localhost:8080
```

## Оновлення фотографій

1. Покладіть нові файли в `new/` (HEIC, JPEG, PNG — будь-що з iPhone).
2. Додайте рядок `ІМʼЯ_ФАЙЛУ|slug` у масив `MAP` в `tools/build-images.sh`.
3. Запустіть:

```bash
brew install webp        # одноразово, якщо cwebp ще не встановлено
bash tools/build-images.sh
```

Скрипт розгортає HEIC, робить три ширини (640 / 1280 / 1920) у JPEG і WebP
та кладе результат у `assets/img/`. Оригінали в репозиторій не потрапляють.

## Адмін-панель

У футері кожної сторінки, праворуч унизу, є непомітна **іконка-шестерня**.
Натисніть її → введіть код **2283** → відкриється панель редагування.

### Що можна змінювати

- **Тексти** — 175 полів на 5 сторінках. Кожне з людською назвою («Головний
  заголовок», «Текст картки»), згруповані за секціями сторінки.
- **Фото** — 24 знімки. Нове фото автоматично зменшується до 1920px і
  стискається просто у браузері, тому вантажити можна прямо з телефона.
- **Посилання** — Instagram, YouTube, Facebook, Spotify, Telegram, пошта.
- **ID кліпу** «Ідеальні вони» — після його введення на сторінці «Музика»
  з'являється вбудований плеєр замість кнопки на канал.

Зміни видно одразу, ще до публікації. Вони зберігаються у вашому браузері,
тож сторінку можна закрити й повернутися пізніше — чернетка не зникне.
Кнопка «↺ Повернути» біля поля скасовує одну правку, «Скасувати всі зміни»
у розділі «Публікація» — усі.

### Як опублікувати зміни для всіх

Один раз потрібно налаштувати доступ до GitHub:

1. Відкрийте GitHub → **Settings** → **Developer settings** →
   **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. У **Repository access** оберіть **тільки цей репозиторій**.
3. У **Permissions** увімкніть **Contents: Read and write**. Більше нічого.
4. Скопіюйте токен, у панелі відкрийте розділ **Публікація**, заповніть
   власника й назву репозиторію та вставте токен.
5. Натисніть «Перевірити з'єднання» — має з'явитися зелений напис.

Далі щоразу достатньо кнопки **«Опублікувати»**. Через ~1 хвилину GitHub Pages
оновить сайт, і зміни побачать усі.

Кнопка **«Експорт»** працює завжди й без токена — вивантажує `content.json`,
який можна залити на GitHub вручну. Зручно як резервна копія.

### Що важливо розуміти

- **Код 2283 — це захист від випадкових змін, а не від зловмисника.** Він
  лежить у JavaScript, який видно в коді сторінки. Реальний бар'єр — токен:
  без нього ніхто нічого не опублікує, навіть відкривши панель.
- **Токен зберігається тільки у вашому браузері** (IndexedDB) і ніколи не
  потрапляє у файли сайту. Не вводьте його на чужому чи спільному комп'ютері.
  Кнопка «Вийти» стирає його з пристрою.
- **Не переносьте токен у код** і не робіть репозиторій приватним заради
  безпеки: опублікований сайт усе одно публічний, тож токен із файлів побачить
  будь-хто. До того ж GitHub Pages на безкоштовному плані взагалі не працює
  з приватним репозиторієм.
- **Замінене фото втрачає адаптивні розміри**: замість шести варіантів
  (640/1280/1920 у JPEG і WebP) лишається одне зображення 1920px. Для окремих
  знімків це непомітно; якщо колись оновлюватимете всі фото — краще прогнати
  їх через `tools/build-images.sh`.
- Панель важить ~30 КБ і завантажується **тільки після введення коду**.
  Звичайний відвідувач її не тягне взагалі.

## Що врахував

- **Темна тема без світлої** — свідоме рішення під сценічну естетику.
- **Анімації** — тільки `transform` і `opacity`; `will-change` знімається після
  анімації. Піни вимкнено нижче 900px, курсор і магнітні кнопки — лише на
  desktop.
- **`prefers-reduced-motion`** — анімації не пришвидшуються, а вимикаються
  повністю; Lenis не ініціалізується, завіса переходів не працює.
- **Якщо CDN недоступний** — сайт відкочується до статичної подачі, а не
  лишається порожнім.
- **Доступність** — контраст вище 4.5:1, тач-цілі від 44px, пастка фокуса
  в меню та лайтбоксі, `Esc` і стрілки в галереї, один `<h1>` на сторінку.
- **Перевірено** на 375 / 768 / 1024 / 1440 — горизонтального скролу немає
  на жодній сторінці.
