# YUDYTSKA

Офіційний сайт української співачки Альони Юдицької (YUDYTSKA) — Чернігів.

Статичний сайт: чистий HTML, CSS та JavaScript, без збірки та без залежностей
у репозиторії. Деплоїться на GitHub Pages як є.

---

## ⚙️ Єдине, що потрібно доналаштувати

Посилання на кліп **«Ідеальні вони»** на YouTube. Відкрийте
[`assets/js/config.js`](assets/js/config.js) і вставте ID відео в перший рядок:

```js
export const YT_ID = 'dQw4w9WgXcQ';   // ID з https://youtu.be/<ID>
```

Поки поле порожнє, блок кліпу показує обкладинку синглу з кнопкою на
YouTube-канал — сайт повністю робочий. Після вставки ID там з'явиться
вбудований плеєр.

Усі інші посилання (Instagram, YouTube, Facebook, Spotify, Telegram, пошта,
публікації ЗМІ, радіо) теж лежать у `config.js` — міняти їх треба тільки там,
у розмітці вони підставляються автоматично через атрибут `data-link`.

## Локальний запуск

Модулі ES не працюють через `file://`, тому потрібен сервер:

```bash
python3 -m http.server 8080
# відкрити http://localhost:8080
```

## Оновлення фотографій

1. Покладіть нові файли в `new/` (HEIC, JPEG, PNG — будь-що з iPhone).
2. Додайте рядок `ІМʼЯ_ФАЙЛУ|slug` у масив `MAP` в `tools/build-images.sh`.
3. Запустіть:

```bash
brew install webp        # одноразово, якщо cwebp ще не встановлено
bash tools/build-images.sh
```

Скрипт розгортає HEIC, робить три ширини (640 / 1280 / 1920) у JPEG і WebP
та кладе результат у `assets/img/`. Оригінали в репозиторій не потрапляють.

## Що врахував

- **Темна тема без світлої** — свідоме рішення під сценічну естетику.
- **Анімації** — тільки `transform` і `opacity`; `will-change` знімається після
  анімації. Піни вимкнено нижче 900px, курсор і магнітні кнопки — лише на
  desktop.
- **`prefers-reduced-motion`** — анімації не пришвидшуються, а вимикаються
  повністю; Lenis не ініціалізується, завіса переходів не працює.
- **Якщо CDN недоступний** — сайт відкочується до статичної подачі, а не
  лишається порожнім.
- **Доступність** — контраст вище 4.5:1, тач-цілі від 44px, пастка фокуса
  в меню та лайтбоксі, `Esc` і стрілки в галереї, один `<h1>` на сторінку.
- **Перевірено** на 375 / 768 / 1024 / 1440 — горизонтального скролу немає
  на жодній сторінці.
